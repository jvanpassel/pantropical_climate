This repository includes the R code from the manuscript 'The 2023–2024 El Niño as a Preview of Future Tropical Forest Climate'
- r_script_pantropical_climate includes the R code to analyze the climate products over 2000-2024 and to create figures 1 to 3.
- r_script_pantropical_cmip includes the R code to calculate the probability ratios from the CMIP6 climate projections over 2025-2100 and to create figure 4.
